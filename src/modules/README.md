# modules

Изолированные бизнес-модули. Каждый модуль — своя папка `src/modules/<module-name>/` со стандартной структурой:

- `components/` — «тупые» компоненты, без знания про Redux
- `containers/` — компоненты, использующие `useSelector`/`useDispatch`
- `slices/` (или `reducers/`) — логика состояния
- `effects/` — side-effects (API, сложные сценарии) на RxJS
- `selectors/` — выборка данных из стора
- `models/` — типы/интерфейсы и модели данных
- `utils/`, `constants/` — вспомогательная логика

Модули не должны импортировать друг друга напрямую — переиспользуемое выносится в `shared/`.
